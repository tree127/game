# 俄罗斯方块 (Tetris)

用 Python + pygame 写的俄罗斯方块。

## 运行

需要 Python 3.9+ 和 pygame-ce：

```bash
pip install pygame-ce
python 俄罗斯方块.py
```

Windows 上也可以直接双击 `启动游戏.bat`（固定使用 Python 3.14.6）。

> 注意：原版 `pygame` 在 Python 3.14 上无法安装，请使用 `pygame-ce`（社区版，`import pygame` 用法完全一致）。

## 操作

方向键与 WASD **都支持**：

| 操作 | 方向键 | WASD |
|------|--------|------|
| 左右移动（可长按） | ← / → | A / D |
| 顺时针旋转 | ↑ | W 或 X |
| 逆时针旋转 | — | Z |
| 软降（可长按） | ↓ | S |
| 硬降 | 空格 | 空格 或 E |
| 暂停 / 重新开始 / 退出 | P / R / ESC | |

## 功能

- 7 种方块，7-bag 随机（出块公平）
- 旋转带踢墙（贴边也能转）
- 幽灵落点预览
- 消行计分（1/2/3/4 行 = 100/300/500/800 × 等级）
- 每消 10 行升一级，下落加速
- 下一个方块预览

## 说明

- **开场屏**：运行后先按任意键 / 点击窗口开始，确保窗口拿到键盘焦点。
- **输入法**：启动时会禁用窗口的输入法（IME），避免中文输入法截走 WASD 字母键。
- **按键手感**：长按连续移动的参数 `DAS` / `ARR` 在 `俄罗斯方块.py` 中可调。
